# HWLN 方位與雷達圖修復：1.5.2

本修正納入正式版本 v1.5.2。這次修改適用 32 方位月報工具，與 PFG／ASD 無關。

## 修正原因

舊程式接受 HWLN 檔名，卻繼續套用原 KLNG 的 21 方位清單，使 M:W 的 11 個方向被主動寫空。實際 HWLN 2026-01-01 原始資料在其中六個方向有符合既有訊息與距離規則的紀錄，因此不能以空白代表未接收資料。

新版本把「選擇哪些方向」和「如何從每個方向選值」分開。此修正恢復被錯誤套用的排除所遮掉的候選，不調整距離、群聚、訊息集合或資料值去配合圖形。

Excel 原生驗收另外發現：舊完整工作簿的 MAXIFS 未使用 XLSX 所需 `_xlfn.` 前綴，開啟後重新計算會出現 `#NAME?`，總表 IFERROR 再將它隱藏為空白。新版也修正 MAXIFS、STDEV.S 的序列化。驗收需比較 Excel 重算值與預期結果，不能只讀取檔案內的 cached values。

## 一般操作

1. 開啟新版 `AIS_32方位月報工具.exe`，確認版本 1.5.2。
2. 選擇原始 AIS 月份資料夾，確認港別及年月。
3. 方位政策選 auto：KLNG 使用 klng21，HWLN／其他站點使用 all32。
4. 雷達樣式選 auto：KLNG 使用原線形，HWLN／其他站點使用填色。也可以明確選 line 或 filled。
5. 選值距離上限仍預設 500 NM。雷達刻度上限留白，讓圖表依結果自動設定；只有需要統一比較尺度時才明確指定足夠大的上限。
6. 選新的輸出資料夾，保留舊版本成果。
7. 執行分析，取得一份 Modern workbook 與五份 Historical delivery workbook。
8. 檢查 M:W：有有效候選的方向應有值，沒有候選的方向仍可留白。在 Modern 決策台帳追查候選、來源列及 Period，不要用補 0 填滿畫面。
9. 完成人工覆核後，由新版重新讀取台帳並產生五份交付。舊版本台帳必須重新分析及覆核，不可直接當新方向政策的完整結果。

## 命令列

```powershell
.\AIS_32方位月報工具.exe `
  --input "D:\AIS\HWLN_202608" `
  --port HWLN --year 2026 --month 8 `
  --direction-policy auto --radar-style auto `
  --output "D:\AIS\修復輸出\HWLN_2026年08月_32方位數值_新版自動分析.xlsx" `
  --delivery-dir "D:\AIS\修復輸出\正式交付\HWLN_202608"
```

以上路徑只是使用範例，不表示本機已取得八月完整來源。必須提供實際原始檔；不能由照片推算未取得的日期。

## 設定語意

| 設定 | 作用 | 不代表什麼 |
| --- | --- | --- |
| auto 方位 | KLNG 用 klng21，其餘用 all32 | 不是依每筆船位自動判斷海陸 |
| klng21 | 重現原 21 方位範圍 | 不是所有站點的通用海向規則 |
| all32 | 32 方位都可輸出有效候選 | 不表示每方向都是海域，也不保證每方向都有 AIS |
| max-distance | 限制可參與選值的距離，NM | 不是雷達圖最大半徑 |
| radar-max | 指定顯示刻度上限，NM | 不改變或排除資料，不可裁掉有效值 |
| line / filled | 原生 Excel 線形／填色雷達 | 不改變群聚或研究值 |

## 驗證與邊界

- KLNG 預設 21 方位、選值及缺值語意持續保留。
- HWLN 缺少人工完整月份 Ground Truth 時，只能宣稱通過程式契約與實際可用原始資料驗證，不宣稱整月已與學長人工結果一致。
- 相同值在 0–150 與 0–300 刻度下所占半徑不同；不同年月圖形不能僅以輪廓大小判定資料正確性。
- 舊輸出不會被新版自動改寫。原始資料一律只讀，新結果與舊結果分開保存。
- 方位政策是影響結果的設定，變更後必須重新驗證。不要把 klng21 與 all32 的結果混為同一方法版本。

## 升級相容性

Cache version 6、review schema AIS_V15_REVIEW_3。方位設定進入快取及覆核身分驗證；normalized spool 仍保留原 numeric 32 分箱語意。舊覆核檔請重新分析，避免舊 HWLN 缺失方向被誤認成已覆核空白。
